- Layers
- Link layer
	- mac to mac 
	- one hop
- Transport layer
	- ip to ip
	- multiple hops
- internet Layer
	- Port to Port
	- Multiple hops + going to a specific server/service
	- TCP/UDP
- Application Layer
	- application to server

- Packets are in a frame
- the frame has
	- From 
	- To
	- Type
	- Payload
	- FCS - Frame check sequence

	

- Network typologies
	- BUS
	- MESH
	- STAR
	- HYBRID

Mac address 
4 pairs of hex code - unique to each computer

Connection Hierarchies:
- P2P
- Client Server
- Listen Server

Gateway
a set IP address on a LAN that computers can access a wider network with

Public - Private IP
public IP is the ip of the gateway
private IP is the of the computer on the LAN behind the Gateway
